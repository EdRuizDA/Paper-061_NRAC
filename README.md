# Paper-061---NRAC
This repository includes the time series data for the rain gauge stations, along with the Jupyter Notebook used to generate the results.

To view the results, download the .csv files corresponding to each station and save them in a designated folder.

Next, in the "Inputs" section of the Jupyter Notebook file, specify the path to that folder—this will be stored in the variable pathEst. Finally, provide the path to the directory where you want the output results to be saved ("pathOutput").
